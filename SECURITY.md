# Biztonsági hibák jelentése

Ha biztonsági hibát találsz a telepítőben vagy a Solutronban, **ne nyiss róla nyilvános issue-t.**

Jelentsd a GitHub privát sérülékenység-bejelentő felületén: a repó **Security** fülén, a **Report a vulnerability** gombbal.

Kérjük, írd le:
- az érintett verziót (a telepítő a napló első sorában kiírja),
- a hiba reprodukálásának lépéseit,
- a lehetséges hatását.

Minden bejelentést visszaigazolunk, és a javítás után nyilvánosan is közzétesszük.
